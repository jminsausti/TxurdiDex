# TxurdiDex

Aplicación didáctica incremental para el aprendizaje
de Vue.js en 2.º de Desarrollo de Aplicaciones Web.

## Objetivos

- Aprender Vue 3 mediante un proyecto práctico.
- Desarrollar la aplicación progresivamente.
- Mantener la correspondencia con los apuntes ES/EU.
- Trabajar reactividad, componentes, HTTP, Router y Pinia.

## Estado

Fase inicial de análisis y planificación.
